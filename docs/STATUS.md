## 拡張の読み込み手順（人の操作）

1. Chromeで `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
2. 「パッケージ化されていない拡張機能を読み込む」で `extension/` フォルダを選ぶ。
3. YouTubeのタブを再読み込みする。コードを更新したときは拡張の再読み込みボタン→YouTubeの再読み込み。
4. 拡張アイコンのポップアップでモード切り替え・登録・このタブの判定件数を確認できる。
