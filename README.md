# YouTube Channel Filter — 自作拡張の開始資料

作成日: 2026-10-27 / 状態: **M1試作を実装済み・実サイト未検証。** 現状は [STATUS.md](docs/STATUS.md)。テスト: `node --test tests/*.test.js`

既存の第三者製拡張を導入せず、自分で内容を確認できる小さな拡張を作る。YouTubeで指定チャンネルの動画を非表示にする効果と限界を、実際の画面で確かめながら開発する。

## 最初に作るもの

- PCのChrome向けManifest V3拡張。Edgeはその後に別途確認する。
- 自分で指定したチャンネルを対象に、検索結果の通常動画カードから検証を始める。
- 「停止」「判定のみ」「非表示」を切り替える。初期設定は「判定のみ」。
- 外部ライブラリなし、拡張独自のネットワーク通信なし、設定はブラウザ内に保存する。
- ホーム・関連動画は段階的に追加し、再生スキップは別の後続実験にする。

拡張本体は `extension/`（ビルド不要）。パッケージのインストールやアカウント設定の変更は行っていない。
